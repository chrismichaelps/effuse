## Capability details

- **Streaming responses** — Sends a `ReadableStream` body without buffering it whole.
- **Request cancellation** — Surfaces client disconnects on `request.signal`.
- **Graceful shutdown** — `close()` drains in-flight requests before terminating.
- **Multipart bodies** — Accepts `multipart/form-data` request bodies.
- **Multiple Set-Cookie** — Preserves multiple `Set-Cookie` response headers.
- **Ephemeral port** — Binds an OS-assigned port via `port: 0`.

## Not yet shipped

- Edge/serverless adapters (Vercel, Netlify, Cloudflare Workers) — a documented adapter contract only; no reference implementation in this release.
- Per-adapter cold-start, throughput, and memory numbers — tracked with the performance lab (issue #249).
